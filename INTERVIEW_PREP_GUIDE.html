PrepAI — Interview Preparation Notes

A clean, simple-language cheat sheet covering architecture, tech stack, and top interview questions.

1. Project Overview (The 30-Second Answer)

"What is PrepAI?"
"PrepAI is a full-stack, production-grade interview preparation platform built with Python (Flask 3.0), MySQL 8.x (SQLAlchemy 2.x), and Google Gemini AI. It allows candidates to generate custom interview questions (including MCQs and coding), practice under real-time countdown pressure with text or voice, receive instant AI evaluations scored on Clarity, Relevance, and Conciseness, bookmark questions, and track preparation progress on a dashboard."

2. Tech Stack & Why Chosen

Component Technology Why Chosen?

AI Engine Google Gemini (gemini-2.5-flash) Fast inference, cost-effective, native support for strict JSON schema output.

3. Core Features & How They Work

  • User Authentication: Email and password registration with salted hashes (generate_password_hash). Protected routes use @login_required via Flask-Login.
  • AI Question Generator (/questions): Custom questions and model answers across Technical, Behavioral, HR, System Design, MCQ, and Coding.
  • Interactive Practice Mode (/practice/<id>): Flashcard-style question practice with instant checking for MCQs and accuracy tracking.
  • Timed Mock Interview (/mock-interview): Client-side countdown timer (e.g. 120s) with automatic submission when time expires.
  • Voice Mode (/voice-interview): Questions read aloud via speechSynthesis and candidate responses transcribed in real time via SpeechRecognition.
  • Rubric-Based AI Feedback: 10-point scoring on Clarity, Relevance, and Conciseness, plus strengths, areas for improvement, and ideal educational answers.
  • Question Library & Bookmarks (/library, /bookmarks): Search, filter by difficulty/type, and bookmark questions for targeted revision.
  • Progress Dashboard (/dashboard): Displays total questions practiced, unique topics covered, accuracy %, and weakest topic insights.

4. Database Design

Relational tables managed in MySQL via SQLAlchemy 2.x models with composite indexes:

  • users: id (UUID PK), email (unique), password_hash, full_name, target_role, created_at, updated_at.
  • question_sessions: id, user_id (FK with CASCADE), topic, question_type, difficulty, questions (JSON text), created_at.
  • mock_interviews: id, user_id (FK with CASCADE), topic, role, difficulty, seconds_per_question, items (JSON text), overall_score, status, completed_at, created_at.
  • bookmarks: id, user_id (FK with CASCADE), session_id (FK with CASCADE), question_index, note, created_at.
  • practice_attempts: id, user_id (FK with CASCADE), session_id (FK), topic, question_type, difficulty, question_text, user_answer, correct_answer, is_correct, score, time_taken_seconds, created_at.

Design Choice: SQLAlchemy cascade deletes ensure clean tenant cleanup. Composite indexes on (user_id, created_at DESC) provide fast dashboard queries.

5. AI Integration & Prompt Engineering

  • Guaranteed Valid JSON: PrepAI uses Gemini's structured output mode (response_schema / JSON output) to guarantee valid JSON without broken formatting.
  • Evaluation Prompt: Instructs Gemini to act as a strict technical interviewer, scoring Clarity, Relevance, and Conciseness (0–10) while providing actionable feedback.
  • Error & Rate Limit Handling: Catches HTTP 429 and timeout exceptions, returning clean, non-blocking alert messages to the user.

6. Security & Defensive Coding

  • Password Hashing: Uses Werkzeug's cryptographic salted hashing. Raw passwords are never stored.
  • CSRF Protection: Flask-WTF protects all web forms and asynchronous JSON endpoints (X-CSRFToken header).
  • Session Hardening: HttpOnly=True (prevents XSS cookie theft), SameSite="Lax" (prevents CSRF), Secure (HTTPS auto-enabled).
  • Data Isolation: All queries filter by current_user.id to guarantee tenant isolation.
  • Defensive Clamping: Custom helpers clamp_int() and clamp_score() prevent negative numbers, buffer overflow, and invalid scores.
  • Fail-Fast Connectivity: Startup check tests MySQL connectivity immediately, halting with clear diagnostics if MySQL is unavailable.
  • Secret Protection: API keys reside exclusively in .env and cloud environment variables, protected by .gitignore.

7. Top 10 Common Interview Questions & Simple Answers

Q1: "Why did you build PrepAI?"
"Most candidates prepare passively by reading answers, but freeze in real interviews. PrepAI creates active practice with a countdown timer, voice answering, and instant structured feedback."
Q2: "What is the high-level architecture?"
"It's a modern MVC application. Flask handles routing, sessions, and JSON APIs. MySQL with SQLAlchemy handles persistence with connection pooling. Jinja2 and Vanilla JavaScript handle the UI, timers, and browser speech APIs."
Q3: "Why choose Flask over Django?"
"Flask is lightweight and unopinionated. It gave us direct control over routes, custom authentication, and fast JSON endpoints without Django's configuration overhead."
Q4: "Why MySQL? How was the migration handled?"
"We upgraded from SQLite to MySQL to support production concurrency, connection pooling, and multi-user scaling. We engineered a verified, idempotent migration script (migrate_sqlite_to_mysql.py) that safely reads SQLite data, validates row counts, and transfers records into MySQL with zero data loss."
Q5: "How do you make sure the AI response doesn't break your app?"
"We enforce a strict JSON schema using Gemini's native structured outputs (responseSchema). The API is guaranteed to return valid JSON with our exact expected fields."
Q6: "How does the voice feature work?"
"It uses the browser's native Web Speech API. SpeechRecognition transcribes the candidate's speech to text in real time, while speechSynthesis reads the questions aloud. No expensive third-party audio service is needed."
Q7: "What happens if a user's browser doesn't support speech?"
"The app checks for window.SpeechRecognition. If unavailable (e.g., Firefox without flags), it shows a friendly warning and lets the user practice seamlessly in typed mock interview mode."
Q8: "How do you secure user data and sessions?"
"Passwords use Werkzeug salted hashes. Cookie sessions are hardened with HttpOnly and SameSite. CSRF tokens protect all state-changing endpoints. All database operations are scoped to current_user.id so users can only view their own data."
Q9: "Why use PrepAI instead of ChatGPT?"
"ChatGPT is a generic chat box with no structure. PrepAI provides a complete interview workflow: countdown timers that simulate pressure, voice input/output, a standardized 3-criteria grading rubric, and progress tracking."
Q10: "What are the current limitations and what would you build next?"
"Current areas for expansion: integrating sandboxed code execution (e.g. Pyodide or isolated Docker runners) for live coding challenges, and collaborative peer mock interviews."
